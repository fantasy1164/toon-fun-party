# 明星總動員歡樂派對

給妍卉和向澤的 iPad 網頁遊戲：在遊戲中學習生活知識、養成好習慣。
純靜態網頁，部署在 GitHub Pages，進度存在裝置的 localStorage。

## 安裝到 iPad

1. 用 Safari 開啟 GitHub Pages 網址。
2. 分享 → 加入主畫面。
3. 從主畫面的圖示開啟，就是全螢幕。請橫放使用。

  - 超市・陪去買東西（小松鼠栗栗）：先點圖片做購物清單（一起玩一人選兩樣）、帶環保袋；到超市螢幕變暗，找到清單上的東西就點一下；排隊結帳、跟店員說謝謝
  - 廁所・陪洗澎澎（嘟嘟）：iPad 放浴室外面，準備睡衣浴巾、請爸媽放水試水溫；洗頭、搓身體、沖水都自動計時用聲音提醒；擦乾穿睡衣按勾勾

測試日期、時間、天氣也可以在家長頁面的「開發測試」設定（主畫面 app 沒辦法改網址）；也可以勾選「不限制每次遊玩時間」讓角色在測試時不下班；那裡也有清除資料：回到今天一開始、回到 30 天前、全部清除。

測試用網址參數：

| 參數 | 作用 |
|---|---|
| `?hour=20.5` | 假裝現在是 20:30（測日夜、領獎時段、睡覺時間） |
| `?session=1` | 每次遊玩時間改成 1 分鐘（測角色下班） |
| `?quake=1` | 進選房間就地震演習（每次載入一次） |
| `?date=2026-12-24` | 假裝今天是某一天（測聖誕節：12/1、12/24 晚上、12/25） |
| `?weather=rain` | 假裝目前天氣（clear、cloudy、rain、storm、fog、hot、cold、windy） |
| `?notts=1` | 不播放佔位語音 |
| `?debug=1` | 左下角顯示語音事件（查 iOS 不說話的問題） |
| `?tgfast=60` | 「一起做」的計時快 60 倍（測睡前、吃飯、功課的長計時） |

## 立體感鏡頭（所有畫面）

`js/core/camera.js`：main.js 呼叫 `setupStageCamera(stage)`，之後每個畫面換上來就自動裝鏡頭，場景程式不用改。

- 畫面裡的東西包進 `.cam-world` 一起跟著鏡頭推拉平移；背景（第一張 1200x900 的圖）在 world 裡再多一點相對移動，最前景（草叢、盆栽）動最多，看起來有景深。各元素原本的前後順序不變。
- 不動的 UI：回家、陳列櫃、時間圓餅、輪流頭像，以及 z-index 10 以上、或之後才加到畫面上的東西（領獎卡片、陳列櫃、拖曳中的圖）。
- 用 CSS 的 `translate`、`scale` 屬性（不是 `transform`），場景自己的 transform 動畫（地震搖晃等）會疊加上去。
- 鏡頭：進場由遠推近、平常慢慢呼吸、點東西時往那邊靠一點並推近、傾斜 iPad 跟著動（陀螺儀）。
- 拖曳超過 12px 時鏡頭自動回到正中間停住，放手 0.6 秒後恢復，場景用舞台座標判斷放下的位置才準。需要精準操作的關卡也可以 `cameraOf(root).hold(true)`。
- 各畫面的設定在 `REGISTRY`／`PRESETS`（戶外、室內、車內、地圖、房子、首頁）；場景要自己指定中景、步道時，先呼叫 `cameraFor(root, {...})`（例：動物園）。
- 光線與影子依現實時間（早上光從左邊來、傍晚偏橘、晚上偏藍）。
- 家長頁「畫面立體感」：鏡頭運鏡可整個關掉；陀螺儀傾斜可單獨關掉。效能測試：家長頁 → 開發測試 → 立體感效能測試（`perf-test.html`）。

## 產生角色語音

- `node tools/check-lines.mjs`：檢查台詞表有沒有重複的台詞代號（同一個代號寫在兩段，前面那個角色的台詞會不見、遊戲裡沒聲音）


角色的聲音與說話風格設定在 `tools/voice-config.json`，台詞在 `js/data/lines.js`。

    $env:GEMINI_API_KEY = "你的金鑰"     # PowerShell；金鑰不要寫進任何檔案
    node tools/gen-voice.mjs --dry        # 先看會產生哪些
    node tools/gen-voice.mjs --line hello # 先做一句試聽
    node tools/gen-voice.mjs              # 產生全部還沒有的（同一角色每 25 句串成一次請求，再依停頓切開）
    node tools/gen-voice.mjs --batch 5    # 切不開時，改小批一點
    node tools/gen-voice.mjs --single     # 一句一次請求（最穩、最耗額度）
    git add -A; git commit -m "角色語音"; git push

- 已存在的檔案會跳過；改了台詞或聲音要重做，加 `--force`（可搭配 `--char dudu` 或 `--line hello`）。
- 有安裝 ffmpeg 會輸出 mp3，沒有則輸出 wav，遊戲都能播。`--convert` 可把現有 wav 轉成 mp3，不呼叫 API。
- 腳本會自動更新 `assets/voice/manifest.json`；沒有語音檔的句子，遊戲會退回裝置內建語音。

新增 js 檔案時，記得加進 `sw.js` 的 `CORE` 清單，並把 `CACHE` 版本號加一。
