雲端同步測試（Google Drive）

只測「登入 → 寫一個小檔案 → 讀回來」，不會動到遊戲進度。請在 iPad、iPhone 的主畫面 app 裡從家長頁點進來測，電腦用瀏覽器開即可。

0. OAuth 用戶端 ID

用戶端 ID 是公開的識別碼，不是密碼。

1. 登入（兩種方式都試）

A 是一般做法；B 是 A 在主畫面 app 失敗時的備案；C 測試權杖過期後能不能不打擾小孩自動續上（A 成功後再按）。

2. 寫入、讀回

在 A 裝置寫入，到 B 裝置按「讀回來」，看到 A 的裝置名稱和時間就代表跨裝置成功。
